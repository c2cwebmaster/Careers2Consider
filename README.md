# Careers to Consider Website

A modern, responsive website for Careers to Consider with multiple pages.

## Pages

- **index.html** - Home page with hero section, logo, team photo, and representation image
- **about.html** - About Us page with "Our Story" section
- **interns.html** - Interns page with "Apply For an Interview" section
- **season1.html** - Season 1 Careers page
- **season2.html** - Season 2 Careers page
- **contact.html** - Contact Us page with contact form
- **more.html** - More page for additional resources

## Required Images

Please add the following images to the `images/` directory:

1. **images/logo.png** - Careers to Consider logo (compass with "careers to consider" text)
2. **images/team.jpg** - Picture of the whole Careers to Consider team (5 girls)
3. **images/representation.jpg** - Cartoon representation of 5 people from different careers standing back to back

## Features

- Responsive design that works on all devices
- Modern, clean UI with smooth animations
- Mobile-friendly navigation menu
- Active page highlighting in navigation
- Contact form with validation
- Smooth scrolling and transitions

## Setup

1. Create an `images/` directory in the project root
2. Add the required images listed above
3. Open `index.html` in a web browser

## Social Media Links

Update the YouTube and Instagram links in the navigation and hero sections to point to your actual social media accounts.
